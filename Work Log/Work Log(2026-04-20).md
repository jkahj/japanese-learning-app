## Completed Today

### 1. Vocab Tab — 全部辭書 Mode
- Added a **模式 toggle** at the top of the vocab tab:
  - 📚 **精選 (30)** — original 30 hand-crafted words (default)
  - 🌐 **全部辭書 (N個)** — loads all JMdict words for selected levels
- Added **pagination** (60 words per page) with ‹ 前頁 / 後頁 › controls
- 全部辭書 loads only the levels selected on the welcome screen (e.g. N5+N4 → ~11,000 words)
- JLPT filter bar (N5/N4/N3/N2/N1) works correctly in both modes
- Status dots (未學/學習中/複習/已精通) visible on every dict word card
- Search box updated to support English keyword search in 全部辭書 mode

### 2. JMdict Data Loading Fix
- **Root cause fixed**: dict files store data as arrays `[reading, pos, [defs]]` but code was accessing `.r / .p / .j / .d` properties (all `undefined`)
- `loadDictLevel()` now converts arrays → objects `{r, p, j, d}` at load time and **tags each word with its JLPT level** (`j: lv`)
- This also fixed the 辭書 tab search (reading + definition search now works correctly)

### 3. onclick Quoting Bug Fix
- `onclick="openDictModal("食べる")"` — inner `"` from `JSON.stringify` broke HTML attribute parsing; clicks did nothing
- Fixed everywhere by using `data-word="${safeWord}"` + `onclick="openDictModal(this.dataset.word)"`
- Applied to both 全部辭書 vocab cards and 辭書 tab search rows

### 4. Rich Dict Word Modal
Every JMdict word now opens a full-detail modal matching the curated word style:

| Section | Details |
|---|---|
| Header | Big kanji · hiragana reading · auto rōmaji · JLPT badge · POS badge |
| 英語定義 | All definitions numbered (JMdict source) |
| 活用・変化 | Auto-generated conjugation table (9 forms for verbs, 6 for adjectives) |
| 例句 | 2 auto-generated template sentences from POS + conjugation forms |
| 常見搭配 | Clickable chips — other dict words sharing a kanji with current word |
| 相關詞 | Clickable chips — same-POS words sharing a kanji |
| 學習狀態 | ⬜ 未學 / 🟡 學習中 / 🔵 複習 / 🟢 已精通 (saved to localStorage) |
| 個人筆記 | Notes textarea with save button (saved to localStorage) |

### 5. New Helper Functions Added
- `toRomaji(str)` — hiragana/katakana → rōmaji converter (full table incl. double consonants, ん→m rule)
- `autoConjugate(word, reading, pos)` — full conjugation for v1, v5*, vk, vs, adj-i, adj-na
- `autoExamples(word, reading, pos)` — 2 template example sentences per POS
- `findCollocations(word)` — scans dictState.data for words sharing a kanji (up to 6)
- `findRelatedWords(word, pos)` — same as above but filtered to same POS (up to 5)
