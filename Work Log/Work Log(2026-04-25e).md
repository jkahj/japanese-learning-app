## Completed Today

### "Add to Curated List" Feature ✅

#### How It Works

1. **Storage**: Promoted words saved to `localStorage` key `jp_promoted` as a JSON array of full VOCAB-compatible objects.
2. **Startup merge**: An IIFE `loadPromotedVocab()` runs immediately after the `VOCAB` array declaration — it reads `jp_promoted` and pushes each word into `VOCAB` (deduplicating by `id` and `kanji`).
3. **UI**: A **⭐ 加入單字帳** button appears in the header of both dict modals.
4. **State transitions**:
   - Not in VOCAB → `⭐ 加入單字帳` (yellow, clickable)
   - Already promoted → `✓ 已加入單字帳` (green, disabled)
   - Original curated word → `✓ 精選單字` (dim, cursor:default)

#### Button safety: `data-promote` attribute
Instead of encoding data in inline `onclick` parameters (which breaks with Japanese quotes), all word metadata (kanji, reading, jlpt, posCode, defs) is stored as `data-promote='{"k":"...","r":"...","j":"...","p":"...","d":["..."]}`. The handler `handleAddToCurated(btn)` reads `btn.dataset.promote` and parses it.

#### Functions Added

| Function | Purpose |
|---|---|
| `loadPromotedVocab()` | IIFE at startup — merges `jp_promoted` into VOCAB |
| `getPromotedList()` | Read `jp_promoted` from localStorage |
| `savePromotedList(arr)` | Write to `jp_promoted` |
| `isInCurated(kanji)` | Check if word already in VOCAB |
| `normPosCode(raw)` | Normalize Jisho verbose POS → filter posCode ('verb','noun','adj-i','adj-na','adv') |
| `addToCurated(kanji, reading, jlpt, posCode, defs)` | Build entry, push to VOCAB, save to storage |
| `removeFromCurated(kanji)` | Remove promoted word (utility, not yet UI-exposed) |
| `curatedBtnHTML(...)` | Render button HTML for modals |
| `handleAddToCurated(btn)` | Click handler — calls addToCurated, updates button state, flashes vocab tab |
| `getPitchNum(kanji, reading)` | Raw accent number (separate from getPitchHTML) — stored in entry.pitch |

#### Promoted Entry Schema
```js
{
  id: 10000+,           // sequential, above all hand-crafted IDs
  kanji: '決める',
  hiragana: 'きめる',
  romaji: 'kimeru',
  pitch: 2,             // from NHK PA lookup
  posCode: 'verb',      // normalized via normPosCode()
  pos: '動詞',
  meanings: ['決定', '確定'],
  jlpt: 'N3',
  conj: null, transIntrans: null,
  examples: [], collocations: [],
  nuance: null, antonyms: [], similar: [],
  tags: ['#自選'],      // yellow badge, distinct from regular tags
}
```
