## How It Works

1. When a flashcard renders, `loadCardImage(w)` is called asynchronously.
2. It checks whether the word is a **concrete noun** (`posCode === 'noun'` for VOCAB words; `pos.includes('名詞')` for dict words).
3. If yes, it extracts an **English search term** from the word's meanings (first ASCII meaning string, cleaned of parenthetical notes).
4. It checks **localStorage cache** (`jp_img_cache`) — if already fetched, the cached URL is used immediately.
5. If not cached, it calls **Unsplash API** (`/photos/random?query=…&orientation=squarish&content_filter=high`).
6. The returned photo URL is cached and the image is injected into `#fc-img` on the card front.
7. The flashcard height expands from `290px` → `370px` via the `.has-image` CSS class.

## Configuration

Open `index.html` and find this line (around line 15973):

```js
const UNSPLASH_ACCESS_KEY = 'PASTE_YOUR_UNSPLASH_ACCESS_KEY_HERE';
```

Replace `PASTE_YOUR_UNSPLASH_ACCESS_KEY_HERE` with your Unsplash **Access Key** (not Secret Key).

Get the key from: https://unsplash.com/developers → Your App → Access Key

## Caching Strategy

| Key | Value |
|---|---|
| `jp_img_cache` | `{ "search term": "https://images.unsplash.com/…" }` |
| Max entries | 300 |
| Eviction | When full, oldest 50 entries are removed |
| Known miss | Empty string `""` is cached to avoid re-fetching failed searches |

---

## What Triggers an Image

| Condition | Shows image? |
|---|---|
| Word is a noun (`posCode === 'noun'`) | ✓ Yes |
| Dict word with `pos` containing `名詞` | ✓ Yes |
| Verb, adjective, particle, conjunction | ✗ No |
| Unsplash key not set / placeholder | ✗ No (silently skipped) |
| Fetch fails / no result | ✗ No (cached as miss) |
