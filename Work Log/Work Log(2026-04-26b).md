# Work Log — 2026-04-26 (Session B)

## Session Summary
Implemented SRS (Spaced Repetition System) scheduling for the flashcard and quiz tabs.
Cards are now prioritised by review-due-date instead of purely by rotation order.

---

## What Changed

### 1. SRS interval table
```js
// srsLevel:      0   1   2   3   4   5
const SRS_INTERVALS = [1, 3, 7, 14, 30, 30]; // days until next review
```
Level rises on ✓, falls on ✗. Intervals double roughly every step (Anki-style SM-2 lite).

### 2. `addDays(n)` + `srsNextDate(level)` helpers
Two small utility functions that turn a level number into a future `YYYY-MM-DD` date string.

### 3. `fcAnswer(correct)` — now writes `nextReview`
```js
const nextReview = correct ? srsNextDate(newLevel) : getTodayStr();
setWD(w.id, { srsLevel: newLevel, status: statusMap[newLevel], nextReview });
```
- **Correct** → `nextReview` = today + interval for the new level
- **Wrong** → `nextReview` = today (word appears again tomorrow as a due card)

The field is stored in `jp_data` alongside `srsLevel` and `status`.

### 4. `buildDailyWords()` — SRS-aware card selection
Cards are now split into three buckets before picking:

| Bucket | Condition | Behaviour |
|---|---|---|
| **due** | `nextReview` set, `≤ today` | Always included, sorted oldest-due-first |
| **fresh** | `nextReview` not set | New words, rotated through the seen-set |
| **future** | `nextReview > today` | Skipped today |

Daily set = **all due cards** + up to **20 new cards** from unseen fresh pool.
This guarantees reviews are never skipped even on days with many due cards.

### 5. `getDailyCards()` — passes `dueCount` / `newCount` through
Both values are cached in `jp_daily` and returned with the card list.
When loading from cache (same-day re-visit), `dueCount` is recomputed live in case
new cards became due since the cache was written.

### 6. `renderDailyBanner()` — shows due/new breakdown
The banner now has a small row below the subtitle:
- 🔁 複習 N  (red, if any due cards)
- ✨ 新學 N  (teal, if any new cards)

### 7. `initFlashcard()` sort removed
The old secondary sort by `srsLevel` is no longer needed because `buildDailyWords()`
already orders: due (oldest first) → new. The sorted order is preserved as-is.
