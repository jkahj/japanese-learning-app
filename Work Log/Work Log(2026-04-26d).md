## Changes to index.html

| Change | Why |
|---|---|
| `<link rel="manifest">` | Connects the PWA manifest |
| `<meta name="theme-color">` | Red chrome bar on Android |
| `apple-mobile-web-app-*` meta tags | Enables full-screen mode on iOS |
| `<link rel="apple-touch-icon">` | iOS home screen icon |
| `<link rel="icon">` | Browser tab favicon |
| `viewport-fit=cover` | Extends into notch area on iPhone X+ |
| `env(safe-area-inset-*)` on body | Keeps content away from notch/home-bar |
| Service worker registration | Registers sw.js on page load |
| iOS install nudge | Red banner on iOS Safari (dismissible, shown once) |

## Service Worker Caching Strategy

| Resource type | Strategy | Cache name |
|---|---|---|
| App shell (index.html, JS, icons) | Stale-while-revalidate | `jp-shell-v1` |
| Dict data (`*_dict.js`, `pitch_accent.js`) | Cache-first | `jp-dict-v1` |
| Firebase / Google APIs | Network-only (never cached) | — |
| Everything else | Network-first, cache fallback | `jp-shell-v1` |

The large `pitch_accent.js` (1.2 MB) is cached after first load — subsequent visits are instant even offline.

## How to Install on iPhone

1. Open the app in **Safari** (must be Safari, not Chrome)
2. Make sure you're serving it via HTTP (`python -m http.server 8080` or Live Server)
3. Tap the **Share** button (rectangle with arrow) at the bottom
4. Scroll down → tap **"加入主畫面" (Add to Home Screen)**
5. Tap **Add** — the app icon appears on your home screen
6. Open it from the home screen — runs fullscreen with no browser chrome

---

## How to Install on Android

1. Open the app in **Chrome**
2. Tap the **⋮ menu** → **"Add to Home Screen"**
   OR wait for Chrome's automatic install prompt
3. Tap **Install**
