# Work Log — 2026-04-22 (Session B)

## Session Summary
Continued development of the Japanese Learning App (`index.html`). This session covered four features: dark/light mode switcher, Jisho proxy improvements, no-repeat flashcard scheduling, and a vocab filter panel redesign.

---

## Completed Today

### 1. Dark / Light Mode Switcher
- Added a ☀️/🌙 toggle button to the top-right of the header
- **Early-init inline script** in `<head>` applies the saved theme before first paint — eliminates flash of wrong theme on reload
- Preference persisted in `localStorage` as `jp_theme` (default: `dark`)
- Icon logic: shows ☀️ in dark mode (click → go light), 🌙 in light mode (click → go dark)
- Full light mode override block added to CSS (`[data-theme="light"]`):
  - New CSS variables: `--bg: #f0f2f8`, `--card: rgba(255,255,255,.82)`, `--border: rgba(0,0,0,.09)`, `--text: #1a2035`, etc.
  - Every element that used hardcoded dark colours overridden: header, nav, both modal types, flashcard faces, quiz options, grammar cards, dict rows, progress bars, welcome screen, level-selection cards, all buttons/inputs, scrollbar, JLPT level badges

### 2. Jisho CORS — Expanded to 10 Proxies + Retry Button
- **Problem**: All 4 unique proxy services occasionally fail simultaneously
- **Fix**: Expanded race from 7 endpoints (4 unique services) → 10 endpoints (7 unique services)
- **3 new providers added**: `cors.eu.org`, `yacdn.org/proxy`, `api.cors.lol`, `proxy.cors.sh`
- **Minimum 2-character guard**: single-char queries (e.g. `1`) now show "請輸入至少 2 個字" without hitting any proxy
- **Retry button**: error state now shows 🔄 重新嘗試 button that clears `_jishoFastProxy` and re-races all 10 endpoints fresh

### 3. No-Repeat Flashcard Scheduling
- **Problem**: Daily cards were seeded by date only — words could repeat on consecutive days
- **Fix**: Added `jp_seen_v2` localStorage entry tracking which words have been shown this cycle
  - Each day's 20 words are added to the seen set after selection
  - Next day's pool = all level words **minus** already-seen words
  - When pool empties (all words shown), cycle counter increments and seen set resets
  - Seen set is keyed by `lvKey` (e.g. `"N5"`) — changing levels resets the cycle automatically
- **Banner enhancements**:
  - Progress bar showing `seenCount / totalWords` (e.g. `20 / 800`)
  - **第 N 輪** yellow badge when on cycle 2+
  - **🎉 全部學完！重新開始** notice on the day a cycle resets
  - ✨ 新的一天！notice on normal new-day transitions

### 4. Vocab Filter Panel Redesign
- **Problem**: 3 `.toolbar` divs wrapping chaotically — JLPT row was cut off, 狀態 and 詞性 shared the same line, labels were misaligned mid-sentence
- **Fix**: Replaced with a single `.vocab-filters` glassmorphism card, 5 clean rows each with a 36px fixed-width uppercase label column

| Row | Label | Content |
|---|---|---|
| 1 | 模式 | 📚精選 · 🌐全部辭書 · [🔍翻譯驗證 →right] |
| 2 | 搜尋 | Full-width search input |
| 3 | JLPT | 全部 · N5 · N4 · N3 · N2 · N1 |
| 4 | 狀態 | 全部 · ⬜未學 · 🟡學習中 · 🔵複習 · 🟢已精通 |
| 5 | 詞性 | 全部 · 動詞 · い形 · な形 · 名詞 · 副詞 |

- Rows separated by 1px `var(--border)` dividers
- Works in both dark and light mode (light override added)
- Zero JS changes — all `onclick` handlers unchanged
