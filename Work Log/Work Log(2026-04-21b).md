## Completed Today

### 1. Example Sentence Overhaul — Template Improvement
- **Problem**: `autoExamples()` used 2 hardcoded templates per POS, producing nonsensical sentences like `胡坐があります。` / `胡坐が好きです。` for every noun
- **Fix**: Expanded to 7–9 templates per POS category, with a deterministic word-hash seed (`sum of char codes`) so different words get different sentence pairs
- Templates now include proper subjects and natural contexts:
  - Verbs: `〜たことがありますか。` / `一緒に〜ますか？` / `〜てみてください。` etc.
  - adj-i: `この料理はとても〜です。` / `そんなに〜ですか。` etc.
  - adj-na: `彼女はとても〜な人です。` / `〜な雰囲気が好きです。` etc.
  - Nouns: `〜について話しましょう。` / `彼の〜はとても印象的でした。` etc.

### 2. Gemini AI Example Sentences — Attempted & Removed
- Added Gemini `gemini-2.0-flash` API for generating contextual example sentences
- **Error 1**: 404 — model name `gemini-2.5-flash-preview-04-17` not found → fixed to `gemini-2.0-flash`
- **Error 2**: 429 — quota exceeded on free tier
- **Decision**: Removed Gemini entirely for example generation due to quota limits

### 3. Tatoeba Integration for Example Sentences
- Replaced Gemini with **Tatoeba** (`tatoeba.org/en/api_v0/search`) — free, no API key, no quota
- Sentences are real examples written by native Japanese speakers
- Japanese sentences translated to Traditional Chinese via Google Translate (`sl=ja&tl=zh-TW`)
- Same 5-proxy race system as Jisho for CORS handling:
  - Direct → corsproxy.io → allorigins.win → codetabs → thingproxy
- Results cached in `localStorage` (`jp_ex_v3`) — each word only fetched once
- Falls back to improved templates if Tatoeba has no sentences for a word
- Label shows `（Tatoeba 例句）` for real sentences, `（自動模板）` for fallbacks

### 4. Error Handling Improvements
- Example sentence failures now show exact error message in red with 🔄 重試 retry button
- `retryAiExamples()` clears cache entry and re-fetches on demand
- `_aiExRetryCtx` stores last call context for retry

## Architecture: Example Sentence Flow
```
loadAiExamples(word, reading, pos, defs)
  ├─ Cache hit (jp_ex_v3) → renderExamplesInto(…, 'tatoeba') instantly
  ├─ Miss → show "搜尋中…" loading state
  │    └─ tatoebaExamples(word)
  │         ├─ fetchTatoeba() → Promise.any([5 proxies])
  │         ├─ filter: sentences containing exact word
  │         ├─ jaToZh() → Google Translate ja→zh-TW for each
  │         └─ cache result → renderExamplesInto(…, 'tatoeba')
  └─ On failure → autoExamples() template fallback → renderExamplesInto(…, 'template')
```
