# Work Log — 2026-06-25

## Session Summary
Added two new quiz modes and a register-tag system, differentiating the app from
other Japanese learning tools (WaniKani / Bunpro / Anki / jpdb). All three features
were built on top of existing infrastructure — no new dependencies.

---

## Features Shipped

### 1. 🎧 Listening mode (quiz)
- New mode toggle bar in the Quiz section: **看字 / 聽力 / 克漏字**
- Listen mode auto-plays the word's reading via existing `speakJapanese()` on each
  question, hides the kanji/reading, and shows a large 🔊 replay button
- Options remain the 4 Chinese meanings (same as 看字 mode)
- Persisted in `state.quizMode` so it survives section switches

### 2. ✏️ Cloze (fill-in-the-blank) mode (quiz)
- Blanks the target word in a real **Tatoeba** sentence (reuses `tatoebaExamples()`);
  falls back to a template sentence (`autoExamples()`) when Tatoeba has no match
- Options are the 4 candidate **words**, shown as `word（reading）` so the kanji-only
  version isn't too hard (per user request)
- Sentences pre-fetched in `initQuiz()` while the loading spinner shows; each fetch
  is independently guarded so one failure never breaks the quiz

### 3. 🏷️ Register / "common in the wild" tags
- Tags already existed in data + rendered as chips, but were all the same blue.
  Added `tagChip()` + `TAG_STYLE` map to colour them by category:
  - `#口語` green · `#敬語` amber · `#商務` teal · `#新聞` grey · `#anime` pink · `#漫畫` purple
  - Topic tags (`#生活`, `#日常`, …) stay blue
- Tagged **all 30 curated VOCAB words** with a register tag (0 untagged):
  - `#口語` × 24 (everyday speech)
  - `#商務` × 3 (書く, 便利, 時間)
  - `#新聞` × 3 (読む, 捜す, 少し — the three with formal/written register notes)
