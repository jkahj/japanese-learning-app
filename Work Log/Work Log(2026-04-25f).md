# Work Log — 2026-04-25 (Session F)

## Session Summary
Comprehensive light-mode CSS audit and refinement. Identified 12 categories of rough edges through source-code review, fixed all of them in one targeted CSS block appended to the existing light-mode overrides.

## Issues Found & Fixed

### 1. Pitch Accent bars/label ✅
- **`.ph-lo`** — `rgba(255,255,255,.18)` = white bar on white background = invisible
  → Fixed: `rgba(0,0,0,.14)` (dark gray)
- **`.pitch-label`** — `rgba(255,255,255,.35)` = invisible text
  → Fixed: `rgba(0,0,0,.3)`

### 2. JLPT level badges (b-n1 through b-n5) ✅
All five used neon/pastel colors (`#7eb3ff`, `#5ef5a0`, `#ffe060`, `#ffb347`, `#ff8888`) unreadable on white.
→ Fixed: dark equivalents matching the existing `hlb-n*` pattern (`#1a5ec7`, `#1a7a40`, `#7a5c00`, `#884000`, `#8c1a1a`)

### 3. Utility badges (b-pos, b-tag, b-promoted) ✅
- `b-pos` had near-invisible background and muted text → darkened both
- `b-tag` had `#88b8ff` (too light) → `#1a5ec7`
- `b-promoted` had neon yellow `#ffd740` → amber `#7a5c00`

### 4. Grammar card level badges (gc-n1 through gc-n5) ✅
Same neon-on-white problem as b-n* badges. Fixed with matching dark colors.

### 5. Grammar note box ✅
- `gc-note` border/background barely visible (yellow with low alpha on white)
- `gc-note-label` had `color: var(--yellow)` = invisible
  → Fixed: amber `#7a5c00`

### 6. Nuance box ✅
- `nuance-title` had `color: var(--yellow)` = invisible
- Box background/border barely visible
  → Fixed: amber `#7a5c00` title, darker amber border

### 7. Status button chosen states (learning/mastered) ✅
- `s-learning.chosen` used `var(--yellow)` = invisible
- `s-mastered.chosen` used `var(--green)` = too light
- Applied to both `.st-btn` and `.dm-st-btn`
  → Fixed: amber + dark green

### 8. Flashcard mode button & answer buttons ✅
- `.fc-mode-btn.active` used `var(--red-light)` = `#ff5252` (ok) but now uses `#c0392b` for more contrast
- `.fc-btn-w` and `.fc-btn-c` adjusted for light bg

### 9. Jisho purple elements ✅
- `.jisho-pos`, `.jisho-tag`, `.jisho-powered` all used `#9d8fff` / `#b8b0ff` = very light purple, unreadable
  → Fixed: `#4a3fa0` (dark indigo)

### 10. Add-to-Curated button ✅
- Gold color `#ffd740` invisible on white
- Disabled state green `#00e676` barely visible
  → Fixed: amber `#7a5c00` / dark green `#1a7a40`

### 11. Dict chip strip (N3 level chip) ✅
- `.dchip-n3` uses `var(--n3)` = `#ffd740` = invisible on light bg
  → Fixed: `color:#7a5c00`, `border-color:#c08000`

### 12. Quiz result score ✅
- Red glow `text-shadow` looks odd on white background
  → Fixed: `text-shadow: none`

### Bonus: JMdict vocab card meaning dark-mode fix ✅
- Hardcoded `color:#555` on `.vc-meaning` in JMdict cards was invisible in dark mode (dark gray on dark blue)
- Removed the inline `color` style; `.vc-meaning { color: var(--text-2) }` now applies correctly to both themes
