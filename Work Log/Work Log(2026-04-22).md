## Completed Today

### 1. Jisho CORS — Expanded to 7-Proxy Race
- **Problem**: `jisho.org` still failing with "連線失敗" / "找不到結果" from `file://` and `http://127.0.0.1`
- **Fix**: Expanded proxy race from 4 → 7 parallel endpoints using `Promise.any()`
- **Proxy memory**: `_jishoFastProxy` stores the winning proxy index — subsequent searches skip the race entirely (displays ⚡)
- **In-memory cache**: `_jishoCache[query]` stores results — re-searching the same word is instant
- **Debounce**: Reduced from 350ms → 200ms (safe due to cache hits)
- **Per-attempt timeout**: 9s on race path, 7s on fast path, each with its own `AbortController`

| # | Endpoint | Notes |
|---|---|---|
| 0 | Direct `jisho.org` | Works on HTTP server |
| 1 | `corsproxy.io/?{url}` | Primary proxy |
| 2 | `allorigins.win/raw?url=` | Raw response |
| 3 | `api.codetabs.com/v1/proxy?quest=` | Reliable dedicated proxy |
| 4 | `thingproxy.freeboard.io/fetch/` | Independent provider |
| 5 | `corsproxy.io/?url=` (encoded) | Alternate corsproxy format |
| 6 | `allorigins.win/get?url=` | JSON wrapper; auto-unwrapped via `j.contents` |

### 2. Example Sentence Overhaul — Template Improvement
- **Problem**: `autoExamples()` used 2 hardcoded templates per POS, producing identical nonsensical sentences like `胡坐があります。` / `胡坐が好きです。` for every noun
- **Fix**: Expanded to 7–9 templates per POS category with a deterministic word-hash seed (`sum of char codes mod array length`) so different words get different sentence pairs
- Templates include proper subjects and natural contexts:
  - **Verbs**: `〜たことがありますか。` / `一緒に〜ますか？` / `〜てみてください。` etc.
  - **adj-i**: `この料理はとても〜です。` / `そんなに〜ですか。` etc.
  - **adj-na**: `彼女はとても〜な人です。` / `〜な雰囲気が好きです。` etc.
  - **Nouns**: `〜について話しましょう。` / `彼の〜はとても印象的でした。` etc.

### 4. Tatoeba Integration for Example Sentences
- Replaced Gemini with **Tatoeba** (`tatoeba.org/en/api_v0/search`) — free, no API key, no quota limits
- Sentences are real examples written by native Japanese speakers
- Japanese sentences auto-translated to Traditional Chinese via Google Translate (`sl=ja&tl=zh-TW`)
- Same 5-proxy race system as Jisho for CORS handling:
  - Direct → corsproxy.io → allorigins.win/raw → codetabs → thingproxy
- Results cached in `localStorage` (`jp_ex_v3`) — each word fetched only once per session
- Falls back to improved templates if Tatoeba has no sentences for a word
- Label shows `（Tatoeba 例句）` for real sentences, `（自動模板）` for template fallbacks
- Error handling: shows exact error message in red with `🔄 重試` retry button
- `retryAiExamples()` clears the cache entry and re-fetches on demand; `_aiExRetryCtx` stores last call context

## Architecture: Example Sentence Flow
```
loadAiExamples(word, reading, pos, defs)
  ├─ Cache hit (jp_ex_v3) → renderExamplesInto(…, 'tatoeba') instantly
  ├─ Miss → show "搜尋中…" loading state
  │    └─ tatoebaExamples(word)
  │         ├─ fetchTatoeba() → Promise.any([5 proxies])
  │         ├─ filter: sentences containing exact word
  │         ├─ jaToZh() → Google Translate ja→zh-TW for each
  │         └─ cache result → renderExamplesInto(…, 'tatoeba')
  └─ On failure → autoExamples() template fallback → renderExamplesInto(…, 'template')
```
